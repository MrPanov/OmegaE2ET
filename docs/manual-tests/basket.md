# Ручные smoke-тесты корзины Omega

## Предусловия и данные

- Пользователь авторизован на `https://test.omega.page/` и имеет право создавать счета.
- Эталонная карточка товара: `5614799817`.
- Остатки динамические: положительное значение ищется в складских колонках строки товара; названия и количество складов не фиксируются.
- Для проверки изоляции в корзине заранее оставляют минимум один посторонний товар.

## P0 Smoke

### BASKET-001. Добавление позиции по карточке

1. Открыть корзину.
2. Ввести `5614799817` в `Додати позицію` и нажать Enter.

**Ожидаемый результат:** показано подтверждение добавления; появилась одна строка нужной карточки с кодом, названием, брендом, ценой, количеством и таблицей остатков; повторный Enter не создаёт неконтролируемые дубликаты.

### BASKET-002. Остатки по динамическим складам

1. Найти строку `5614799817`.
2. Сопоставить заголовки складских колонок со значениями следующей строки.

**Ожидаемый результат:** хотя бы в одной складской колонке остаток больше нуля; значение относится к заголовку той же колонки. Тест не зависит от аббревиатур или фиксированного числа складов; агрегатная колонка наподобие `Всі скл.` не выбирается как склад резервирования.

### BASKET-003. В счёт попадает только выбранный товар

1. Иметь в корзине `5614799817` и посторонние позиции.
2. Оставить отмеченным только `5614799817`.
3. Проверить сумму выбранных товаров.
4. Нажать `У резерв`.

**Ожидаемый результат:** чекбоксы всех остальных складских и заказных позиций сняты; сумма равна цене и количеству только `5614799817`; окно выбора склада открывается без ошибки.

### BASKET-004. Выбор склада и создание счёта

1. Запомнить индекс складской колонки с положительным остатком у `5614799817`.
2. Нажать `У резерв`.
3. Выбрать вариант склада с тем же индексом и подтвердить.

**Ожидаемый результат:** создан новый счёт; в деталях указан выбранный склад; единственная товарная карточка — `5614799817`; резерв и сумма рассчитаны для количества 1; посторонние товары остались в корзине и не попали в счёт.

### BASKET-005. Изменение количества

Проверить кнопки `−`/`+` и допустимый ручной ввод количества для складского товара.

**Ожидаемый результат:** количество, сумма строки и общий итог синхронны; нельзя установить ноль, отрицательное, дробное или превышающее доступный остаток значение, если это запрещено правилами продажи.

### BASKET-006. Удаление выбранной позиции

1. Выбрать одну из нескольких строк.
2. Выполнить `Дія → Видалити вибрані товари` и подтвердить действие.

**Ожидаемый результат:** удалена только выбранная строка; остальные позиции, их количество и чекбоксы не изменились; общий итог пересчитан.

### BASKET-007. Выбрать все / снять все

Переключить `Вибрати всі` при наличии складских товаров и товаров под заказ.

**Ожидаемый результат:** состояние дочерних чекбоксов и общий итог согласованы; повторное переключение снимает выбор без удаления строк.

### BASKET-008. Недоступное резервирование

Снять выбор со всех товаров либо выбрать товар с нулевым остатком и попытаться резервировать.

**Ожидаемый результат:** `У резерв` недоступна либо показана понятная валидация; пустой счёт не создаётся; приложение не зависает под overlay.

### BASKET-009. Сохранение состояния

Изменить количество и выбор строк, обновить страницу и повторно открыть корзину.

**Ожидаемый результат:** состояние восстанавливается согласно требованиям продукта; нет дубликатов, потери строк или самопроизвольного выбора чужих товаров.

### BASKET-010. Ошибка API

На тестовом стенде эмулировать 4xx/5xx при добавлении и создании счёта.

**Ожидаемый результат:** показана понятная ошибка без stack trace; товар не исчезает до подтверждённого создания счёта; повторная попытка доступна и не создаёт два счёта.

## Дополнительная регрессия

- Добавление из поиска и каталога приводит к той же строке корзины.
- `Товари зі складу` и `Товари під замовлення` визуально и логически разделены.
- Фильтр склада/бренда не меняет данные скрытых строк.
- Импорт XLS валидирует формат, дубликаты, отсутствующие карточки и количество.
- Клавиатура, фокус, масштаб 200%, мобильная ширина и актуальные Chrome/Edge/Firefox.
- Двойной клик по `У резерв` не создаёт два счёта.
- После создания счёта журнал показывает правильные номер, статус, склад и сумму.
