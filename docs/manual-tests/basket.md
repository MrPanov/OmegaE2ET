# Ручные smoke-тесты корзины Omega

## Предусловия

- Пользователь авторизован в выбранной среде.
- Корзина разделена на две секции: `Товари зі складу` и `Товари під замовлення`.
  Товар попадает в одну из них в зависимости от наличия — проверять строку нужно
  с учётом секции.
- Панель добавления состоит из поля `Додати позицію`, счётчика количества с
  кнопками `−` / `+` и кнопки подтверждения. **Количество задаётся до добавления.**
- Клиент общий: в корзине могут лежать чужие позиции. Каждый сценарий,
  добавляющий товар, обязан удалить за собой только то, что добавил.

## Тестовые данные

Один и тот же товар адресуется двумя разными идентификаторами — это используется
в BASKET-003.

| Идентификатор | Значение |
|---|---|
| Номер карточки | `4610495` |
| Каталожный код | `OC90` |
| Название | Фільтр оливний LANOS, AVEO, LACETTI, NUBIRA, NEXIA (вир-во KNECHT-MAHLE) |
| Производитель | KNECHT/MAHLE |

## Корзина — P0

### BASKET-001. Открытие корзины

Открыть корзину.

**Ожидаемый результат:** страница загрузилась, доступны поле `Додати позицію`,
счётчик количества и кнопка подтверждения; виден `Журнал рахунків`.

### BASKET-002. Добавление по номеру карточки

Убедиться, что товара нет в корзине. Ввести `4610495` в `Додати позицію`,
оставить количество `1`, нажать кнопку подтверждения.

**Ожидаемый результат:** товар добавлен ровно одной строкой в секцию
`Товари зі складу`; в строке отображается код `OC90`, карточка `4610495`,
название и производитель; количество равно `1`.

**Уборка:** удалить добавленную строку, состав остальных строк не изменился.

### BASKET-003. Добавление по каталожному коду не создаёт дубль

Добавить товар по карточке `4610495` с количеством `1`. Затем ввести в то же поле
каталожный код `OC90`, оставить количество `1` и подтвердить.

**Ожидаемый результат:** поле принимает оба идентификатора. Вторая позиция
**не создаётся** — количество в уже существующей строке увеличивается с `1` до `2`.
Общее число строк корзины не изменилось.

**Уборка:** удалить добавленную строку.

### BASKET-004. Добавление заданного количества сразу

Убедиться, что товара нет в корзине. Ввести `4610495`, кнопкой `+` установить
количество `3`, подтвердить.

**Ожидаемый результат:** товар добавлен одной строкой сразу с количеством `3`,
а не с `1`. Итоговая сумма учитывает три единицы.

**Уборка:** удалить добавленную строку.

### BASKET-005. Форма не сбрасывается после добавления

Добавить `4610495` с количеством `3`. Не трогая панель добавления, осмотреть её.

**Ожидаемый результат фиксирует текущее поведение:** поле сохраняет введённое
значение (с хвостовым пробелом — `4610495 `), счётчик остаётся равным `3`.
Повторное нажатие кнопки подтверждения добавит тот же товар ещё раз и увеличит
количество до `6`.

**Риск:** отсутствие сброса формы провоцирует случайный повторный клик. Если
продукт решит сбрасывать поле и счётчик после добавления — ожидаемый результат
этого сценария нужно переписать.

**Уборка:** удалить добавленную строку.

### BASKET-006. Удаление позиции

Запомнить состав корзины. Добавить `4610495`, затем нажать кнопку удаления
в его строке.

**Ожидаемый результат:** строка исчезает **сразу, без диалога подтверждения**.
Целевая карточка отсутствует, состав и количества остальных строк не изменились.

### BASKET-007. Очистка корзины

Добавить в корзину хотя бы одну позицию. Нажать кнопку очистки корзины
(оранжевая, справа от панели добавления).

**Ожидаемый результат:** корзина очищается целиком **без диалога подтверждения**.
Обе секции показывают сообщения
`Кошик ще порожній, скористайтеся пошуком для додавання товарів` и
`Кошик під замовлення ще порожній, скористайтеся пошуком для додавання товарів`.
Общая сумма обраних равна `0.00 грн`, счётчик корзины в шапке обнуляется.

> **Разрушительный сценарий.** Кнопка удаляет все позиции, включая чужие, и
> подтверждения не запрашивает. Выполнять только на корзине, состав которой
> не жалко потерять. Позиции раздела `Товари під замовлення` восстановлению
> в исходном виде не подлежат: повторное добавление создаёт строку с текущими
> складом и датой, а не с исходными.

## Постусловие для всех изменяющих сценариев

После выполнения сценария в корзине не должно остаться товаров, добавленных этим
сценарием. Проверяется явно: искомая карточка отсутствует, а количество строк
совпадает с зафиксированным до начала. Уборка выполняется и в случае падения
сценария на середине.
