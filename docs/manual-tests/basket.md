# Ручные smoke-тесты корзины Omega

## Предусловия

- Пользователь авторизован в выбранной среде.
- Каждый изменяющий сценарий использует отдельную карточку из таблицы ниже.
- Автотест удаляет только добавленный им товар, в том числе после падения.
- Остатки и названия складов динамические и не фиксируются точными значениями.

| Сценарий | Карточка |
|---|---|
| BASKET-002 | `5614799817` |
| BASKET-003 | `651002` |
| BASKET-004 | `46101216738` |
| BASKET-005 | `3211996264` |
| BASKET-006 | `69501396346` |
| BASKET-007 | `4400676052` |
| BASKET-008 | `69101138569` |
| INVOICE-001 | `4610495` |

## Корзина — P0

### BASKET-001. Открытие корзины

Открыть корзину.

**Ожидаемый результат:** страница загрузилась, доступно поле `Додати позицію`, виден `Журнал рахунків`.

### BASKET-002. Добавление по карточке

Ввести `5614799817` в `Додати позицію` и нажать Enter.

**Ожидаемый результат:** появился правильный товар ровно в одной строке. После проверки товар удалён.

### BASKET-003. Отображение данных

Добавить `651002` и проверить строку.

**Ожидаемый результат:** отображаются карточка, код, название, производитель, положительная цена, количество и остатки. После проверки товар удалён.

### BASKET-004. Динамические склады

Добавить `46101216738` и сопоставить каждую складскую колонку со значением по тому же индексу.

**Ожидаемый результат:** число заголовков и значений совпадает; данные не зависят от названий `КВ`, `КВ-Л`, `КВ-ППН`, `ХРК-РС` или появления новых складов; агрегатная колонка `Всі скл.` не считается отдельным складом. После проверки товар удалён.

### BASKET-005. Изменение количества

Добавить `3211996264`, проверить `+`, `−` и ручной ввод недопустимого значения.

**Ожидаемый результат:** количество и итог пересчитываются синхронно; возврат к исходному количеству возвращает исходную сумму; ноль не принимается. После проверки товар удалён.

### BASKET-006. Выбор отдельных товаров

Добавить `69501396346` и оставить отмеченным только этот товар.

**Ожидаемый результат:** общий итог равен цене выбранного товара, умноженной на его количество; чужие товары не учитываются. Исходное состояние чужих чекбоксов восстанавливается.

### BASKET-007. `Вибрати всі`

Добавить `4400676052`, снять, затем установить массовый чекбокс.

**Ожидаемый результат:** массовый чекбокс снимает и выбирает доступные складские
позиции. Строки раздела `Товари під замовлення`, которыми этот флажок не управляет,
не обязаны менять состояние. После проверки исходное состояние чужих чекбоксов
восстанавливается.

### BASKET-008. Удаление позиции

Запомнить остальные карточки, добавить и удалить `6900651126`.

**Ожидаемый результат:** целевая карточка отсутствует, состав остальных строк не изменился.

## Создание счёта

### INVOICE-001. Резервный счёт с одной позицией

Добавить `4610495`, оставить выбранным только этот товар, найти склад с положительным
остатком и нажать `У резерв`. Выбрать соответствующий склад.

**Ожидаемый результат:** создан резервный счёт; в нём находится только `4610495`,
а склад в деталях совпадает с выбранным. Добавленный товар автоматически очищается
из корзины, если создание счёта не завершилось и позиция осталась там.
