# Ручное тестирование поисковой строки Omega

## Область тестирования

Набор покрывает ввод и отправку запросов через глобальную поисковую строку
`VIN, Держ. номер, OE, найменування, картка, код` в авторизованной части Omega.
Проверки содержимого и управления полной поисковой выдачей вынесены в
[`search-results.md`](search-results.md).

## Автоматизация

Все описанные здесь сценарии автоматизированы в
[`SearchTests.cs`](../../tests/UiAutomation.Tests/Tests/SearchTests.cs). Связь
между ручным сценарием и автотестом задаётся атрибутом `TestCaseId`. Набор
содержит 25 автотестов: `SEARCH-BAR-001`–`SEARCH-BAR-009` и
`SEARCH-BAR-011`–`SEARCH-BAR-026`; исключённый `SEARCH-BAR-010` отсутствует.

Проверка сетевых запросов и вставка через буфер обмена выполняются в Chromium.
Между обычными поисковыми запросами выдерживается безопасный интервал, чтобы
полный прогон не превышал ограничение частоты запросов тестового сервера.

## Предусловия

1. Пользователь авторизован на `https://test.omega.page/`.
2. Глобальная поисковая строка отображается и доступна для ввода.
3. Выбрана действующая точка доставки.
4. В справочнике присутствуют эталонные товары из таблицы ниже.
5. Для проверки сетевых запросов открыта вкладка `Network` инструментов
   разработчика с включённым сохранением журнала.

## Тестовые данные

| Назначение | Значение |
|---|---|
| Код товара | `OC90` |
| Карточка | `4610495` |
| Полное название | `Фільтр оливний LANOS, AVEO, LACETTI, NUBIRA, NEXIA (вир-во KNECHT-MAHLE)` |
| Часть названия | `Фільтр оливний LANOS` |
| Код с пунктуацией | `23.129.02` |
| Отсутствующий товар | `zz-no-product-987654321` |

Цены, остатки, сроки доставки и количество аналогов являются динамическими и в
ожидаемых результатах не фиксируются.

## P0 — критические проверки

### SEARCH-BAR-001. Поиск по коду товара

1. Очистить поисковую строку.
2. Ввести `oc90`.
3. Нажать Enter.

**Ожидаемый результат:** открыта вкладка `Результати пошуку`; отображается
`Знайдено по коду: 1`; основной товар имеет код `OC90`, карточку `4610495` и
бренд `KNECHT/MAHLE`.

### SEARCH-BAR-002. Поиск по номеру карточки

1. Ввести `4610495`.
2. Нажать Enter.

**Ожидаемый результат:** отображается `Знайдено по картці: 1`; основной товар
имеет код `OC90` и карточку `4610495`.

### SEARCH-BAR-003. Регистронезависимость кода

1. Выполнить поиск `oc90` и записать основной результат.
2. Выполнить поиск `OC90`.
3. Сравнить основной результат двух запросов.

**Ожидаемый результат:** код, карточка, название и бренд совпадают; изменение
регистра не создаёт дубликаты и не изменяет тип поиска.

### SEARCH-BAR-004. Поиск по полному названию

1. Вставить полное название из тестовых данных.
2. Нажать Enter.

**Ожидаемый результат:** запрос отправлен без потери символов; найдены
релевантные товары `OC90` и `OC90OF`; точные совпадения расположены выше менее
релевантных.

### SEARCH-BAR-005. Поиск по части названия

1. Ввести `Фільтр оливний LANOS`.
2. Нажать Enter.

**Ожидаемый результат:** отображаются релевантные масляные фильтры для LANOS;
выдача не ограничена одним брендом; приложение не сообщает об ошибке.

### SEARCH-BAR-006. Несуществующий товар

1. Сначала выполнить поиск `oc90`.
2. Заменить запрос на `zz-no-product-987654321`.
3. Нажать Enter.

**Ожидаемый результат:** показано сообщение
`За Вашим пошуковим запитом нічого не знайдено.`; результаты предыдущего запроса
удалены; поисковая строка остаётся доступной.

### SEARCH-BAR-007. Новый запрос после предыдущего

1. Выполнить поиск `oc90`.
2. Заменить значение на `4610495`.
3. Нажать Enter.

**Ожидаемый результат:** значение строки и активный запрос равны `4610495`;
сводка изменена на `Знайдено по картці: 1`; новая выдача заменяет старую, а не
добавляется к ней.

### SEARCH-BAR-008. Отправка запроса клавишей Enter

1. Очистить журнал `Network`.
2. Ввести `oc90`.
3. Один раз нажать Enter.
4. Проверить запросы поиска в журнале.

**Ожидаемый результат:** поиск запускается один раз; нет дублирующих запросов;
фокус и поисковая строка не блокируются после загрузки.

### SEARCH-BAR-009. Быстрая отправка двух запросов

1. Ввести `oc90` и нажать Enter.
2. Не дожидаясь окончания загрузки, ввести `4610495` и нажать Enter.
3. Дождаться исчезновения индикатора загрузки.

**Ожидаемый результат:** интерфейс не зависает; итоговая строка, активный запрос,
тип поиска и выдача относятся к последнему принятому запросу; товары из разных
ответов не смешиваются.

## P1 — обработка значения

### SEARCH-BAR-011. Пробелы вокруг запроса

1. Последовательно выполнить поиск `oc90`, ` oc90`, `oc90 ` и `  oc90  `.
2. Сравнить основные результаты.

**Ожидаемый результат:** внешние пробелы нормализуются; все варианты находят
`OC90`; в активном запросе нет лишних пробелов и дубликатов.

### SEARCH-BAR-012. Строка только из пробелов

1. Ввести несколько пробелов.
2. Нажать Enter.

**Ожидаемый результат:** полная выгрузка товаров не запускается; показана
валидация либо сохранено безопасное текущее состояние; ошибок приложения нет.

### SEARCH-BAR-013. Пустое поле

1. Полностью очистить строку.
2. Нажать Enter.

**Ожидаемый результат:** пустой запрос не отправляется как поиск всех товаров;
строка остаётся доступной; текущая страница не ломается.

### SEARCH-BAR-014. Несколько пробелов внутри названия

1. Выполнить поиск `Фільтр оливний LANOS`.
2. Выполнить поиск `Фільтр   оливний   LANOS`.
3. Сравнить поведение.

**Ожидаемый результат:** приложение не показывает ошибку и не зависает; если
внутренние пробелы нормализуются, набор результатов совпадает; иначе показана
корректная пустая выдача.

### SEARCH-BAR-015. Кириллица и латиница

1. Выполнить поиск `Фільтр оливний`.
2. Выполнить поиск `LANOS`.
3. Проверить введённые значения и результаты.

**Ожидаемый результат:** кириллица и латиница не повреждаются и не заменяются
похожими символами; результаты релевантны введённой строке.

### SEARCH-BAR-016. Смешанный регистр в названии

1. Выполнить поиск `Фільтр оливний LANOS`.
2. Выполнить поиск `фІЛьТр ОлИвНиЙ lanos`.
3. Сравнить релевантные результаты.

**Ожидаемый результат:** регистр не влияет на поиск по названию; основные
релевантные товары присутствуют в обоих наборах.

### SEARCH-BAR-017. Код с пунктуацией

1. Ввести `23.129.02`.
2. Нажать Enter.

**Ожидаемый результат:** точки не удаляются и не изменяются; найден товар с
кодом `23.129.02`; приложение не возвращает ошибку сервера.

### SEARCH-BAR-018. Частичный код

1. Ввести `OC9`.
2. Нажать Enter.

**Ожидаемый результат:** частичное совпадение не помечается как точное совпадение
с `OC90`; тип поиска и количество результатов соответствуют правилам поиска;
ошибок приложения нет.

### SEARCH-BAR-019. Длинная строка

1. Вставить строку из 255 безопасных буквенно-цифровых символов.
2. Выполнить поиск.
3. Повторить со строкой из 256 символов.

**Ожидаемый результат:** ограничение длины применяется предсказуемо; строка не
ломает вёрстку; приложение не зависает и не показывает stack trace. Если лимит
отличается от 255 символов, фактическое значение фиксируется в результате теста.

### SEARCH-BAR-020. Вставка через буфер обмена

1. Скопировать `oc90` в буфер обмена.
2. Установить фокус в поисковую строку.
3. Вставить значение через Ctrl+V и нажать Enter.

**Ожидаемый результат:** вставлено полное значение без дополнительных символов;
найден товар `OC90`; ручной ввод и вставка дают одинаковый результат.

## P1 — управление поисковой строкой

### SEARCH-BAR-021. Очистка кнопкой `×`

1. Ввести `oc90`, не отправляя запрос.
2. Нажать кнопку очистки `×` в поисковой строке.

**Ожидаемый результат:** значение полностью удалено; placeholder снова виден;
фокус остаётся в строке либо возвращается в неё при следующем клике.

### SEARCH-BAR-022. Замена значения через Ctrl+A

1. Ввести `oc90`.
2. Нажать Ctrl+A.
3. Ввести `4610495` и нажать Enter.

**Ожидаемый результат:** старое значение полностью заменено; отправлен только
`4610495`; результат соответствует поиску по карточке.

### SEARCH-BAR-023. Опция `шукати "починається з"`

1. Ввести часть существующего кода `OC9`.
2. Включить checkbox `шукати "починається з"`.
3. Нажать Enter.

**Ожидаемый результат:** checkbox визуально отмечен; найденные коды начинаются с
`OC9`; исходный запрос сохраняется.

### SEARCH-BAR-024. Включение и выключение опции

1. Выполнить SEARCH-BAR-023.
2. Выключить `шукати "починається з"`.
3. Повторить поиск `OC9`.

**Ожидаемый результат:** состояние checkbox изменилось; обычная логика поиска
восстановлена; результаты не смешаны с предыдущей выдачей.

### SEARCH-BAR-025. История последних запросов

1. Выполнить запросы `oc90` и `4610495`.
2. Открыть историю поиска соответствующей кнопкой возле строки.

**Ожидаемый результат:** оба запроса отображаются без искажения и дубликатов;
пароли, токены, персональные данные и технические параметры запросов отсутствуют.

### SEARCH-BAR-026. Выбор запроса из истории

1. Открыть историю поиска.
2. Выбрать ранее выполненный запрос `oc90`.

**Ожидаемый результат:** строка содержит `oc90`; выполняется или подготавливается
поиск согласно принятому поведению интерфейса; результат относится к выбранному
запросу, а история не создаёт его дубликат.

## Фиксация результата

Для каждого прогона записать дату, среду, браузер и версию, пользователя/роль,
точку доставки, введённое значение, состояние checkbox, фактический тип поиска и
статус (`Passed`, `Failed`, `Blocked`). В дефекты не добавлять пароль, cookies,
токены и данные реальных клиентов.
