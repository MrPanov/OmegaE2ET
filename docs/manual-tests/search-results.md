# Ручное тестирование поиска и поисковой выдачи Omega

## Область тестирования

Документ покрывает глобальный поиск авторизованной части
`https://test.omega.page/`: ввод запроса в поле
`VIN, Держ. номер, OE, найменування, картка, код`, определение типа запроса,
отображение результатов, фильтры, сортировку, остатки, цены и действия с товаром.

Набор составлен по интерфейсу тестовой среды, проверенному 2 августа 2026 года.
Цены, остатки, сроки поставки и количество аналогов являются динамическими и не
должны фиксироваться в ожидаемом результате точными значениями.

## Предусловия

1. Пользователь авторизован и имеет доступ к ценам и остаткам.
2. Выбрана действующая точка доставки/склад.
3. В справочнике присутствует эталонный товар из таблицы ниже.
4. Корзина тестового пользователя очищена либо её начальное состояние записано.
5. Для проверок сортировки подготовлена выдача минимум из десяти товаров.
6. Для проверки пустого результата используется заведомо отсутствующее значение.
7. Пароли, сессионные данные и данные реальных клиентов не записываются в
   тест-кейсы, дефекты и снимки экрана.

## Тестовые данные

| Тип запроса | Значение | Эталонный результат |
|---|---|---|
| Код товара | `oc90` | Код `OC90`, карточка `4610495`, бренд `KNECHT/MAHLE` |
| Карточка | `4610495` | Код `OC90`, карточка `4610495` |
| Полное название | `Фільтр оливний LANOS, AVEO, LACETTI, NUBIRA, NEXIA (вир-во KNECHT-MAHLE)` | Товары `OC90` и `OC90OF` с соответствующим названием |
| Часть названия | `Фільтр оливний LANOS` | Релевантные масляные фильтры для LANOS |
| Отсутствующий товар | `zz-no-product-987654321` | Пустая выдача |

Перед регрессией нужно подтвердить актуальность эталонного товара у владельца
справочника. Изменение цены или остатка само по себе не является дефектом.

## P0 — критический набор

### SEARCH-001. Поиск по коду товара в нижнем регистре

1. Ввести `oc90` в глобальное поле поиска.
2. Нажать Enter.

**Ожидаемый результат:** открыта вкладка `Результати пошуку`; система определила
запрос как код и показывает `Знайдено по коду: 1`; первым отображается товар
`OC90` с карточкой `4610495`, ожидаемым названием и брендом `KNECHT/MAHLE`;
аналоги визуально отделены от точного совпадения.

### SEARCH-002. Регистронезависимый поиск по коду

1. Выполнить поиск `OC90`.
2. Сравнить результат с запросом `oc90`.

**Ожидаемый результат:** оба запроса находят один и тот же основной товар;
регистр не создаёт дубликаты и не меняет карточку товара.

### SEARCH-003. Поиск по номеру карточки

1. Ввести `4610495`.
2. Нажать Enter.

**Ожидаемый результат:** система показывает `Знайдено по картці: 1`; первым
отображается `OC90` с карточкой `4610495`; результат не интерпретирован как цена,
телефон, VIN или свободный текст.

### SEARCH-004. Поиск по полному наименованию

1. Ввести полное эталонное название из таблицы тестовых данных.
2. Нажать Enter.

**Ожидаемый результат:** система показывает результат поиска по части текста;
отображаются релевантные `OC90` и `OC90OF`; слова, модели автомобилей и
производитель присутствуют в найденных наименованиях; нерелевантные категории не
поднимаются выше точных совпадений.

### SEARCH-005. Поиск по части наименования

1. Ввести `Фільтр оливний LANOS`.
2. Нажать Enter.

**Ожидаемый результат:** найдены масляные фильтры, в наименовании или
применяемости которых присутствует LANOS; выдача не ограничивается одним брендом;
точные совпадения расположены выше менее релевантных.

### SEARCH-006. Заведомо отсутствующий товар

1. Ввести `zz-no-product-987654321`.
2. Нажать Enter.

**Ожидаемый результат:** показано сообщение
`За Вашим пошуковим запитом нічого не знайдено.` и рекомендация проверить
фильтры; старые товары не остаются на экране; страница и новое поле поиска
остаются работоспособными.

### SEARCH-007. Состав строки результата

1. Найти `4610495`.
2. Проверить основной товар в выдаче.

**Ожидаемый результат:** доступны фото или корректный placeholder, код, карточка,
признак аналогов, полное название, бренд, цена с валютой, локальный и общий
остаток, действие просмотра наличия, количество и предусмотренные действия с
товаром; значения не налезают друг на друга и относятся к одной позиции.

### SEARCH-008. Новый запрос поверх предыдущего

1. Найти `oc90`.
2. Не закрывая вкладку результатов, заменить запрос на `4610495`.
3. Нажать Enter.

**Ожидаемый результат:** предыдущая выдача заменена, а не объединена с новой;
тип поиска и информационное сообщение обновились; нет дубликатов из старого
запроса.

### SEARCH-009. Состояние во время загрузки

1. Запустить поиск с широкой выдачей.
2. Сразу попытаться запустить второй поиск или открыть фильтры.

**Ожидаемый результат:** виден индикатор загрузки; затемняющий overlay блокирует
повторные действия только на время запроса и гарантированно исчезает; результат
соответствует последнему принятому запросу; страница не остаётся заблокированной.

### SEARCH-010. Ошибка API поиска

1. В инструментах тестового стенда эмулировать ответ поиска 4xx/5xx или обрыв
   сети.
2. Выполнить запрос.

**Ожидаемый результат:** показана понятная ошибка без stack trace; старые данные
не выдаются как результат нового запроса; доступна повторная попытка после
восстановления сети.

## P1 — обработка поисковой строки

### SEARCH-011. Пробелы вокруг запроса

Сравнить `oc90`, ` oc90`, `oc90 ` и `  oc90  `.

**Ожидаемый результат:** внешние пробелы корректно нормализуются; найден один и
тот же основной товар; в активном фильтре не создаются дубликаты.

### SEARCH-012. Несколько пробелов внутри названия

Сравнить обычное название и вариант с несколькими пробелами между словами.

**Ожидаемый результат:** поведение соответствует требованиям поиска; если
пробелы нормализуются, набор результатов одинаков; иначе пользователь получает
понятный пустой результат, а не ошибку приложения.

### SEARCH-013. Кириллица, латиница и регистр

Проверить `Фільтр оливний`, `фільтр оливний`, `LANOS`, `lanos` и смешанный
регистр.

**Ожидаемый результат:** регистр не влияет на релевантность; кириллица и латиница
не повреждаются; поиск не заменяет символы похожими буквами без явного правила.

### SEARCH-014. Пунктуация и часть кода

Проверить код с дефисом/точкой из существующего товара, часть `OC9`, а также
название со скобками, запятыми и дефисом.

**Ожидаемый результат:** разрешённая пунктуация участвует в поиске корректно;
частичное совпадение не выдаётся как точное; приложение не показывает 500.

### SEARCH-015. Пустое значение и только пробелы

1. Очистить поле и нажать Enter.
2. Повторить со строкой из пробелов.

**Ожидаемый результат:** бесконтрольная полная выгрузка товаров не запускается;
поле остаётся доступным; показана валидация либо сохранено текущее безопасное
состояние.

### SEARCH-016. Длинный запрос

Вставить строку на границе допустимой длины и строку длиннее ограничения.

**Ожидаемый результат:** ограничение применяется предсказуемо; интерфейс не
ломается, запрос не зависает, лишние символы не попадают в URL или логи как
чувствительные данные.

### SEARCH-017. Безопасные специальные строки

Проверить как обычный текст строки `<script>alert(1)</script>`, `" OR 1=1 --`
и набор Unicode-символов. Не использовать разрушающие payload.

**Ожидаемый результат:** строка не исполняется как HTML/JavaScript и не меняет
логику запроса; нет stack trace, раскрытия SQL или данных других пользователей.

### SEARCH-018. Опция `шукати "починається з"`

1. Выполнить поиск части существующего кода с выключенной опцией.
2. Включить `шукати "починається з"` и повторить.

**Ожидаемый результат:** при включении остаются только значения, начинающиеся с
запроса; состояние checkbox видно; выключение возвращает обычную логику поиска.

### SEARCH-019. Действие `Шукати всюди`

1. Выполнить обычный поиск части названия.
2. Нажать `Шукати всюди`.

**Ожидаемый результат:** область поиска расширяется согласно требованиям;
исходный запрос сохраняется; пользователь понимает, почему изменилось количество
результатов; точные совпадения не теряются.

## P1 — управление выдачей

### SEARCH-020. Активный запрос и сброс

1. Выполнить поиск.
2. Проверить активный chip запроса.
3. Удалить chip, затем повторить и нажать `Скинути`.

**Ожидаемый результат:** chip содержит текущий запрос; оба способа сброса очищают
выдачу и связанные фильтры; поле готово к новому поиску.

### SEARCH-021. Сортировка

Для широкой выдачи последовательно проверить:

- `За замовчуванням`;
- `Популярністю`;
- цену по возрастанию и убыванию;
- карточку по возрастанию и убыванию;
- наименование от А до Я и от Я до А;
- бренд от А до Я и от Я до А.

**Ожидаемый результат:** все видимые строки соответствуют выбранному порядку;
пустые значения обрабатываются единообразно; товары не теряются и не
дублируются; выбранный вариант отмечен.

### SEARCH-022. Размер страницы 24/50/100

1. Для широкой выдачи выбрать 24, 50 и 100 элементов.
2. Для каждого значения прокрутить список до конца.

**Ожидаемый результат:** число позиций не превышает выбранное значение до
следующей подгрузки; выбор отображается в меню; изменение размера не сбрасывает
запрос, сортировку и фильтры.

### SEARCH-023. Подгрузка `Завантажити ще...`

1. Выполнить запрос с количеством результатов больше размера страницы.
2. Нажать `Завантажити ще...` несколько раз.

**Ожидаемый результат:** добавляется следующая порция; уже показанные товары не
повторяются; сортировка сохраняется; в конце списка действие исчезает или
становится недоступным.

### SEARCH-024. Табличный и плиточный вид

1. Переключить доступные варианты в блоке `Вид`.
2. Сравнить данные одной позиции.

**Ожидаемый результат:** код, карточка, название, бренд, цена и наличие одинаковы
в обоих видах; выбранный вид сохраняется при работе с выдачей согласно
требованиям.

### SEARCH-025. Возврат Back/Forward и прямой URL

1. Выполнить поиск и применить сортировку/фильтр.
2. Перейти на другую страницу, нажать Back и Forward.
3. Открыть URL выдачи в новой авторизованной вкладке.

**Ожидаемый результат:** запрос и предусмотренное состояние восстанавливаются;
нет пустой страницы; URL не содержит пароль, session ID или персональные данные.

### SEARCH-036. Комплекты

### SEARCH-038. Экспорт и `Зберегти в`

ошибок, содержит текущий запрос и применённые фильтры; колонки и кодировка

### SEARCH-043. Доступность

Проверить программные названия поля, checkbox, кнопок вида, фильтров, сортировки,
количества и действий товара с клавиатурой и screen reader.

**Ожидаемый результат:** интерактивные иконки имеют доступные имена; состояние
checkbox/списков объявляется; сообщение пустой выдачи доступно как alert; порядок
чтения соответствует визуальному.

## Фиксация результата

Для прогона записать дату, среду, пользователя/роль, браузер и версию, точку
доставки, запрос, фильтры, сортировку, количество найденных товаров и статус
(`Passed`, `Failed`, `Blocked`). В дефекте указать фактический тип поиска, первую
нерелевантную позицию, воспроизводимость, время ответа и безопасный снимок экрана.
Не прикладывать пароль, cookies, токены и данные реальных клиентов.
