# Корзина Omega — инструкция для мануального тестировщика

Документ для проверки функционала «Корзина». Рассчитан на человека, который
открывает сайт впервые: расписано, куда нажимать и что должно появиться.

Формальные короткие формулировки кейсов — в [basket.md](basket.md).

---

## Предусловие: вход и переход в корзину

### Шаг 1. Войти на сайт

1. Открыть `https://test.omega.page/`.
2. Появится синяя форма `Для входу введіть свій логін та пароль`.
3. Ввести логин в поле `E-Mail`, пароль — в поле `Пароль`.
4. Нажать `Увійти`.

Если ничего не происходит — проверить раскладку клавиатуры. Форма не подсказывает,
что вместо латиницы введена кириллица.

### Шаг 2. Перейти в раздел «Корзина»

1. В правом верхнем углу найти иконку тележки — рядом с ней показана сумма корзины.
2. Нажать на иконку.
3. Откроется вкладка `Кошик`, адрес станет `.../#/app/basket`.

**Проверка, что вы на месте:** на странице есть поле с подсказкой `Додати позицію`.

### Карта экрана

Сверху вниз:

| Элемент | Где | Назначение |
|---|---|---|
| Блок сумм (ПДВ, СДВ, кредит) | вверху | справочный, в проверках не участвует |
| `Зберегти рахунок`, `У резерв`, `Відвантажити` | справа | **создают реальные документы — не нажимать** |
| Флажок `Вибрати всі` | слева, над панелью | массовый выбор позиций |
| Поле `Додати позицію` | панель добавления | ввод номера карточки или кода |
| `−` `1` `+` | справа от поля | количество, задаётся **до** добавления |
| Кнопка-галочка | правее счётчика | подтверждает добавление |
| Оранжевая кнопка | правый край панели | **очистка всей корзины** |
| `Товари зі складу` | таблица | позиции в наличии |
| `Товари під замовлення` | вторая таблица | позиции под заказ |
| `Загальна сума обраних в кошику` | под таблицами | итог по отмеченным позициям |

Строка товара слева направо: флажок, номер по порядку, каталожный код, номер
карточки, ссылка `(Аналоги)`, название, производитель, колонки складов, цена,
счётчик `−` `1` `+`, крестик удаления у правого края.

### Правила работы

1. **Корзина общая** — в ней могут быть чужие позиции. Удалять можно только своё.
2. **Перед началом переписать состав корзины** — карточки и количества. В конце сверить.
3. **Не нажимать** `У резерв` и `Відвантажити` — создают реальные счета без отмены.

### Тестовые данные

| Что | Значение |
|---|---|
| Номер карточки | `4610495` |
| Каталожный код того же товара | `OC90` |
| Название | Фільтр оливний LANOS, AVEO... (KNECHT-MAHLE) |
| Шина | `15106DOT24` — см. примечание в MT-08 |
| Несуществующий запрос | `zz-no-product-987654321` |

**Цена меняется день ото дня** (встречались `111.30`, `130.06`, `159.06`).
Эталонной цены нет — проверяется только арифметика «цена × количество = сумма».

## MT-01. Добавление товара по номеру карточки

1. Убедиться, что карточки `4610495` в корзине нет.
2. Кликнуть в поле `Додати позицію`.
3. Ввести `4610495`.
4. Проверить, что счётчик справа показывает `1`.
5. Нажать кнопку-галочку.
6. Подождать 2–3 секунды.

**Ожидаемый результат:** появилась одна строка в разделе `Товари зі складу`.
В ней код `OC90`, карточка `4610495`, название с `Фільтр оливний`, производитель
`KNECHT/MAHLE`, цена больше нуля, количество `1`. Всплыл тост
`Кошик / Товар був доданий ...`. **Флажок строки отмечен автоматически.**

**Уборка:** удалить строку крестиком.

## MT-02. Добавление по каталожному коду `OC90`

Смысл: `OC90` и `4610495` — **один и тот же товар**, записанный кодом и карточкой.
Система обязана распознать это и не создать дубль.

1. Добавить `4610495` количеством `1` (как в MT-01).
2. Записать, сколько всего строк в корзине.
3. Кликнуть в поле `Додати позицію`, **полностью стереть** прежнее значение.
4. Ввести `OC90`.
5. Счётчик оставить `1`.
6. Нажать галочку.

**Ожидаемый результат:** новая строка **не появилась**. Количество в существующей
строке выросло с `1` до `2`. Общее число строк не изменилось.

**Если появилась вторая строка — дефект.**

**Уборка:** удалить строку `4610495`.

## MT-03. Удаление позиции кнопкой «Видалити позицію»

1. Переписать состав корзины: карточки и количества всех строк.
2. Добавить `4610495`.
3. Навести курсор на крестик у правого края его строки — появится подсказка
   `Видалити позицію`.
4. Нажать крестик.

**Ожидаемый результат:** строка исчезает **сразу, без вопроса «Вы уверены?»**.
Карточка `4610495` отсутствует; состав и количества остальных строк не изменились.

> Один клик удаляет позицию без возможности отмены. Промахнуться по чужой
> строке легко — сверяйте номер карточки перед нажатием.

## MT-04. Очистка корзины *(опционально, только в регрессии)*

> **РЕГРЕССИОННЫЙ. Разрушительный. Не выполнять в обычном прогоне.**
>
> Кнопка удаляет **все** позиции, включая чужие, и ничего не переспрашивает.
> Позиции раздела `Товари під замовлення` восстановить в прежнем виде
> **невозможно**: при повторном добавлении они получат текущие склад и дату,
> а не исходные. Выполнять только по согласованию с владельцем тестового клиента.

1. Убедиться, что в корзине есть хотя бы одна позиция — **при пустой корзине
   оранжевой кнопки на экране нет**.
2. Нажать оранжевую кнопку у правого края панели добавления.

**Ожидаемый результат:** корзина очищена целиком без подтверждения. Обе секции
показывают `Кошик ще порожній, скористайтеся пошуком для додавання товарів`
и `Кошик під замовлення ще порожній, ...`. Сумма выбранных `0.00 грн`,
счётчик у иконки тележки обнулился.

> Кнопка исчезает с задержкой в пару секунд — Angular проигрывает анимацию.
> Если проверяете её отсутствие, обновите страницу.

## MT-05. Добавление товара в количестве 3 шт

1. Убедиться, что карточки `4610495` в корзине нет.
2. Ввести `4610495` в поле `Додати позицію`.
3. Нажать `+` рядом с полем **два раза** — счётчик покажет `3`.
4. Нажать галочку.

**Ожидаемый результат:** добавилась **одна строка сразу с количеством `3`**,
а не с `1`. Сумма внизу равна цене, умноженной на три.

> Частая ошибка: нажать галочку раньше, чем выставить количество. Счётчик
> действует только **до** подтверждения — потом добавится одна штука.

**Уборка:** удалить строку.

## MT-06. Добавление товара с партнёрских мостов ⚠️ ЧЕРНОВИК

> **Не проверено на живом сайте.** Шаги ниже — заготовка, требующая уточнения
> перед использованием. Известно только со слов постановщика: такой товар
> **нельзя добавить через поле `Додати позицію`**, только через поиск.

Требуется уточнить перед финализацией:

- какой конкретно товар с партнёрского моста брать (код или карточку);
- как отличить партнёрский мост в выдаче поиска — по колонке склада, по метке,
  по цвету;
- в какой раздел корзины он попадает — `Товари зі складу` или `Товари під замовлення`;
- что именно происходит при попытке добавить его через поле `Додати позицію`:
  тост об ошибке, тишина или другое поведение.

Предполагаемая структура сценария:

1. Ввести идентификатор товара в поле `Додати позицію` и подтвердить.
2. Зафиксировать результат — ожидается, что товар **не добавится**.
3. Найти тот же товар через поиск (см. MT-07) и добавить оттуда.
4. Проверить, что позиция появилась в корзине.

## MT-07. Добавление товара из поиска ⚠️ ЧЕРНОВИК

> **Не проверено на живом сайте.** Известно: строка поиска расположена в шапке,
> подсказка `VIN, Держ. номер, OE, найменування, картка, код`. Как именно
> из результатов поиска товар кладётся в корзину — не проверялось.

Требуется уточнить перед финализацией:

- каким элементом товар добавляется из выдачи — кнопка, иконка тележки, клик
  по строке;
- задаётся ли количество прямо в выдаче или только после переноса в корзину;
- переходит ли пользователь в корзину автоматически или остаётся в результатах;
- показывается ли тост о добавлении.

Предполагаемая структура сценария:

1. Ввести код товара в строку поиска в шапке и нажать Enter.
2. Дождаться выдачи.
3. Добавить нужную позицию в корзину элементом управления в строке результата.
4. Перейти в корзину и убедиться, что позиция появилась с верными кодом,
   карточкой и количеством.

## MT-08. Добавление шины в корзину ⚠️ УТОЧНИТЬ КОД

> **Расхождение в данных.** В задании указан код `15106DOT24`. При осмотре
> корзины наблюдалась шина с кодом **`15104DOT24`** (карточка `14961389362`,
> `Шина 195/70R14 91T N-BLUE HD PLUS (Nexen) DOT24`, NEXEN). Отличие в одном
> символе. Перед прогоном уточнить, какой код верен: возможно, это разные
> товары, а возможно — опечатка.

1. Убедиться, что шины в корзине нет.
2. Ввести код шины в поле `Додати позицію`.
3. Оставить количество `1`, нажать галочку.

**Ожидаемый результат:** добавилась строка с шиной — код, карточка, название
с указанием размера и производителя, цена больше нуля, количество `1`.

**На что обратить внимание:** шина может попасть в раздел `Товари під замовлення`,
а не `Товари зі складу`. Проверять наличие строки нужно **в обеих таблицах** —
частая ошибка при проверке.

**Уборка:** удалить строку.

## MT-09. Изменение количества уже добавленного товара

> Счётчик **в строке товара** и счётчик **в панели добавления** — разные
> элементы. Здесь работаем со строкой.

1. Добавить `4610495` количеством `3`.
2. Записать цену из строки и текущую сумму внизу.
3. Нажать `−` **в строке товара** (не в панели сверху).
4. Проверить количество и сумму.
5. Нажать `+` в строке.
6. Выделить содержимое поля количества в строке, ввести `0`, увести фокус.
7. Довести количество до `1` кнопкой `−`, затем нажать `−` ещё раз.

**Ожидаемый результат:**

- шаги 3–5: количество меняется `3 → 2 → 3`, сумма пересчитывается сразу
  и на каждом шаге равна «цена × количество»; после шага 5 сумма вернулась
  к записанной на шаге 2;
- шаг 6: **ноль не принимается** — значение возвращается к `1`;
- шаг 7: количество остаётся `1`, ниже единицы не опускается, строка
  при этом **не удаляется**.

**Уборка:** удалить строку.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Нажал галочку, ничего не появилось | Подождать пару секунд, затем проверить тост — возможно, товар не найден |
| Не вижу кнопку очистки | Корзина пуста — кнопка появляется только при наличии позиций |
| Не увидел сообщение об ошибке | Тост живёт меньше пяти секунд, повторить и смотреть сразу |
| Товар добавился дважды | Панель не очищается после добавления — вероятно, галочка нажата повторно |
| Не нахожу добавленный товар | Проверить **вторую** таблицу — `Товари під замовлення` |
| Разлогинило посреди проверки | Войти заново, состояние корзины хранится на сервере |
| Случайно удалил чужую позицию | Отмены нет. Записать номер карточки и сообщить владельцу клиента |

## Завершение любой проверки

1. Сверить состав корзины с записанным в начале.
2. Убедиться, что добавленных вами карточек не осталось.
3. Количества чужих строк должны совпадать с исходными.
